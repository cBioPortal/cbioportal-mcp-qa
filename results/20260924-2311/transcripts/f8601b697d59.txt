## Best way to add clinical data to cBioPortal

**If you're loading data into your own cBioPortal instance (self-hosted):**

cBioPortal expects clinical data as **tab-delimited text files** with a specific format, loaded alongside a study's genomic data:

1. **File types:**
   - `data_clinical_patient.txt` — one row per patient (e.g., SEX, AGE at diagnosis, OS_STATUS, OS_MONTHS)
   - `data_clinical_sample.txt` — one row per sample (e.g., SAMPLE_ID, PATIENT_ID, CANCER_TYPE, TUMOR_PURITY)

2. **Header format:** Clinical files require a 4-line metadata header before the column header row:
   ```
   #Patient Identifier	Sex	...
   #Identifier to uniquely specify a patient.	Sex of the patient	...
   #STRING	STRING	...
   #1	1	...
   PATIENT_ID	SEX	...
   ```
   (name / description / datatype / priority, then the actual column headers)

3. **Metadata file:** Each clinical file needs a matching `meta_clinical_patient.txt` / `meta_clinical_sample.txt` specifying `cancer_study_identifier`, `genetic_alteration_type: CLINICAL`, `datatype: PATIENT_ATTRIBUTES` or `SAMPLE_ATTRIBUTES`, and the data filename.

4. **Standard columns:** Use cBioPortal's reserved column names where possible (`OS_STATUS`, `OS_MONTHS`, `SEX`, `AGE`, `SAMPLE_TYPE`, etc.) so survival analysis, oncoprint annotations, and cross-study comparisons work out of the box.

5. **Loading:** Use the `cbioportal/importer` Docker image or `metaImport.py` / `cbioportalImporter.py` scripts from the [cBioPortal GitHub](https://github.com/cBioPortal/cbioportal) to validate and import the study folder (clinical + genomic data together).

6. **Validation:** Always run the bundled **validation script** (`validateData.py`) first — it catches header/format errors before import.

**If you just want to add or edit clinical attributes for a study you already see in the portal** (not self-hosting), that's done by the study's data curators/submitters, not through the public web interface — you'd need to contact the study owner or, for public TCGA/GENIE-type studies, this isn't user-editable.

**Full reference:** the official file-format docs are at [docs.cbioportal.org — File Formats: Clinical Data](https://docs.cbioportal.org/file-formats/#clinical-data), which has the authoritative header spec and reserved attribute list.
