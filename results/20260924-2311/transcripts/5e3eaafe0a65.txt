There is no `data_clinical_outcomes.txt` format in the cBioPortal file spec, and this ClickHouse database stores clinical data as ingested attributes, not as the original flat files, so I can't search it for a specific filename.

A few possible things you might actually mean:

1. **A study that has a `TIMELINE` file** for clinical events (e.g., treatment, outcomes over time) — these are `data_timeline.txt` / `meta_timeline.txt`, which do model clinical outcomes/events.
2. **A study with rich survival/outcome attributes** (OS, PFS, DFS, response to treatment) that you could use as a template for building your own patient/sample clinical file.
3. **A specific dataset outside the standard cBioPortal spec** — e.g., something in the `resource_*` tables (external links) or a GDC/other portal export that literally uses a file named `data_clinical_outcomes.txt`.

Could you clarify:
- Are you looking to **emulate the file structure** (i.e., want an example of a well-formed clinical/outcomes file + its meta file to use as a template for your own study upload)?
- Or are you trying to find a **specific existing study** that already ships a file literally named `data_clinical_outcomes.txt`?

If it's the former, I can pull up a TCGA or MSK study with comprehensive outcome/survival attributes and point you to its clinical data file structure (attribute names, meta file format) as a template. Let me know which direction you want, and I'll proceed.
