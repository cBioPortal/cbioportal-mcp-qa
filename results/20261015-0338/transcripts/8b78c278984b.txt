## What I *can* offer instead (all grounded in actual cBioPortal data)

Aneuploidy is measured from copy-number data, and cBioPortal holds that. The closest valid proxies are:

1. **Copy-number alteration (CNA) burden** — total/weighted copy-number events per cancer type, which captures the chromosomal instability that "aneuploidy" typically proxies.
2. **Mutation burden (TMB)** — the mean/median number of non-synonymous mutations per sample, per cancer type.
3. **CNA burden vs. mutation burden correlation** across the Pan-Cancer cancer types — i.e., a per-cancer-type table and a correlation. This is a legitimate correlation question, but I'll note that a correlation across the Pan-Cancer set should be interpreted carefully (it's a modest number of "points" — one per cancer type — and I'd report Spearman with a caveat rather than a clean R²).
